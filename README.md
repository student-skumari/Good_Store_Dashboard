# Good_Store_Dashboard
Good Store Sales Dashboard – Power BI Project

The Good Store Dashboard is an interactive Power BI report designed to analyze sales performance, profit trends, and customer purchasing behavior. This dashboard provides a comprehensive overview of store operations by visualizing key metrics such as total sales amount, profit, quantity sold, and average order value (AOV).

The dashboard enables users to track monthly profit trends, compare sales performance across states, and evaluate product category and sub-category contributions. It also highlights customer purchasing patterns and preferred payment modes, helping businesses understand their revenue drivers.

📈 Dashboard Features

Monthly Profit Analysis to track sales performance throughout the year

Category-wise Quantity Distribution showing product demand across Clothing, Electronics, and Furniture

State-wise Sales Performance highlighting top-performing regions like Maharashtra and Madhya Pradesh

Sub-Category Sales Analysis identifying high-performing products such as Printers and Sarees

Payment Mode Distribution including COD, UPI, Debit Card, Credit Card, and EMI

Customer-wise Sales Analysis to identify top purchasing customers

🛠 Tools Used

Power BI – Data visualization and dashboard creation

Data Analysis – Sales and customer behavior insights

This dashboard helps businesses monitor sales performance, identify profitable products, and make data-driven decisions to improve store revenue and customer engagement.
